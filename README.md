# Лабораторная работа №3 (MPI)

Параллельное умножение квадратных матриц с использованием технологии MPI на суперкомпьютере «Сергей Королёв».

## Состав проекта
- `matrix_mpi.cpp` — исходный код MPI-программы.
- `run_experiments.py` — скрипт автоматизации экспериментов (генерация данных и постановка задач в очередь SLURM).
- `plot_mpi.py` — скрипт построения графиков по результатам.
- `Makefile` — файл сборки.
- `results/` — выходные данные (CSV с замерами и графики).
- **`REPORT.md` — полный текст отчета с графиками и анализом.**
